# UKS-2025
Repository otvoren za potrebe studentskog projekta

*Osnovne tacke:
- Kompletan razvoj se radi na grani koja sadrzi rijec feature u sebi
- Push na github je dozvoljen samo na 'push' granu. Ako grana ne sadrzi rijec 'push', push ce traziti da se odradi CR bar jedna potvrda.
- Ideja je da ko radi na razvoju ima svoju granu koja sadrzi 'push' u imenu, i da na njoj moze n puta odraditi komitovanje. Kada zavrsimo razvoj potrebno je pokrenuti PR prema 'feature' grani kako bi se odradila kompletna provjera CR/CI
- **Sledeci korak je da uvedemo pravilo za startovanje CI alata
